# Just Drop

**Just Drop** is an open-source Android application for transferring files between devices connected to the same Wi-Fi network.

No cloud storage or external server required. Just connect to the same network and send files directly between devices.

## Features

* 📱 Discover nearby devices on the local network
* 📤 Send multiple files to another device
* 📥 Accept or decline incoming transfers
* 📊 Track transfer progress
* 🔒 Transfer files locally without uploading them to a cloud service

## Requirements

* Android 10 (API 29) or later
* Both devices must be connected to the same Wi-Fi network

## Installation

Download the latest APK from the [GitHub Releases](https://github.com/1owmark/Just-Drop/releases) page and install it on your Android device.

## Built With

* Kotlin
* Jetpack Compose
* Ktor
* Kotlinx Serialization
* AndroidX DataStore

## Building from Source

1. Clone the repository:

   ```bash
   git clone https://github.com/1owmark/Just-Drop.git
   ```

2. Open the project in Android Studio.

3. Let Gradle sync and download the required dependencies.

4. Build and run the app on your Android device.
